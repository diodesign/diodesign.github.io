## The mission

Here in the diodesign lab, we wander off the beaten track to see what happens when we mix new programming environments, self-organizing stacks, and a little too much curiosity. Sometimes we release those experiments into the wild for others to use or build upon.

## Ongoing projects

Our current public projects include:

Diosix
: An open-source bare-metal multiprocessor hypervisor written in Zig for 64-bit RISC-V systems. It aims to be secure, lightweight, and reliable, with plans to support decentralized distributed computing. See the [Diosix website](https://diosix.org/).

diodesign.org
: This website, featuring a dot-matrix cellular-automata splash screen, a homegrown Python-based static CMS, and an AI-powered site search. The search function uses a model built into Chrome to answer questions about the site's content. See the site's [source code](https://github.com/diodesign/diodesign.github.io).
